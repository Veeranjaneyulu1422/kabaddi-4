# Kabaddi Scout - Android App with Generative AI

## 📌 Overview
Kabaddi Scout is an Android application developed as part of my internship at **MindMatrix** in collaboration with **R L Jalappa Institute of Technology**.  
The project focuses on **Android App Development using Generative AI**, leveraging modern tools like **Kotlin**, **Jetpack Compose**, and **Google AI Studio** to build intelligent, user-friendly mobile applications.

---

## 🎯 Objectives
- Gain hands-on experience in Android development with **Kotlin** and **Jetpack Compose**.
- Explore **Generative AI** capabilities for enhancing app features.
- Implement **Firebase integration** for authentication and data storage.
- Apply **UI/UX design principles** for better user experience.
- Practice debugging, testing, and iterative development workflows.

---

## ⚙️ Features
- 📱 Modern Android UI built with **Jetpack Compose**.
- 🤖 AI-powered features using **Google AI Studio**.
- 🔥 Real-time database and authentication with **Firebase**.
- 🎨 Interactive dashboards and learning modules.
- 🛠️ Project-based learning with structured workflows.

---

## 🛠️ Tech Stack
- **Language:** Kotlin  
- **Framework:** Jetpack Compose  
- **IDE:** Android Studio  
- **Cloud Services:** Google Cloud Labs, Firebase  
- **AI Tools:** Google AI Studio (GenAI)
